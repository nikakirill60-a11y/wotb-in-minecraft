# WoTB x Minecraft (Forge 1.12.2)

Мод, добавляющий управляемый боевой танк с механиками **World of Tanks Blitz** в Minecraft 1.12.2.

Готовый к установке `.jar` файл находится в:
`wotbminecraft-beta/releases/wotbminecraft-beta-0.2.0-beta.jar`

Подробное описание управления, типов снарядов (ББ / КС / ОФ), системы бронирования и рецептов крафта — в [`wotbminecraft-beta/README.md`](wotbminecraft-beta/README.md).
