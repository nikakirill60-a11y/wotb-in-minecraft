# WoTB x Minecraft — BETA 0.1.0 (Minecraft Forge 1.12.2)

Драйвабельный танк в Minecraft. Пока это **бета с временной моделью из коробок** —
настоящая модель танка встанет на её место без переписывания логики.

## Что умеет бета

- Танк ставится предметом **«Спавнер бета-танка»** (вкладка «Транспорт» в креативе)
- Посадка — **правый клик** по танку
- Езда: **W / A / S / D** (A/D — поворот, танк умеет разворачиваться на месте)
- Башня следует за направлением взгляда игрока, ствол поднимается/опускается
- **G** — выстрел. Снаряд летит с лёгкой баллистикой и взрывается. Перезарядка — 2 секунды
- У танка 100 HP, при уничтожении взрывается
- Крафт спавнера в выживании:
  ```
  [#][#][#]    # — железный блок
  [#][R][#]    R — блок красного камня
  [T][T][T]    T — железный слиток
  ```

## Установка

1. Minecraft **1.12.2** + Forge **14.23.5.2860** (именно Java Edition)
2. Файл `releases/wotbminecraft-beta-0.1.0-beta.jar` — в папку `.minecraft/mods`
3. Нужна **Java 8** (у лаунчеров для 1.12.2 обычно уже есть)

## Известные ограничения беты

- Модель — заглушка (коробки + камуфляжная текстура)
- Нет топлива, боекомплекта, брони/пробитий и HUD с прочностью
- Снаряд разрушает блоки (взрыв), на серверах осторожно

## Сборка из исходников (для разработки)

Нужна JDK 8:
```bash
./gradlew build
```
Готовый мод появится в `build/libs/`. Код замены модели — только класс
`client/model/ModelTankPlaceholder.java`: у сущности танка уже есть отдельные
`turretYaw` (поворот башни) и `turretPitch` (наклон ствола).

## Что прислать для настоящей модели

Положи файлы в папку `incoming_model/` или просто прикрепи к сообщению.
От лучшего варианта к приемлемому:

1. **Blockbench**: файл проекта `.bbmodel` + текстура `.png`
2. **OBJ**: `.obj` + `.mtl` + все текстуры одним архивом
3. **glTF**: `.glb` (сконвертирую)

Важно для правильной анимации в игре:
- **Отдельными частями**: корпус, башня, ствол (маска пушки), гусеницы левая/правая
- Точка вращения башни — по центру погона башни
- Точка вращения ствола — в месте крепления к башне (чтобы наклонялся, а не плавал)
- Напиши реальную длину танка в метрах или блоках — для масштаба
- Текстуру лучше в разрешении, кратном 2 (128, 256, 512...)
