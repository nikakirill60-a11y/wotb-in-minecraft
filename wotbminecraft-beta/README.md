# WoTB x Minecraft — BETA 0.2.0 (Minecraft Forge 1.12.2)

Мод, переносящий боевые танки и механики **World of Tanks Blitz** в Minecraft 1.12.2:
бронебойные, кумулятивные и осколочно-фугасные снаряды, система бронирования (лоб / борта / корма) с приведённой бронёй и рикошетами, снайперский прицел с индикатором бронепробития, танковый HUD, спаренный пулемёт, форсаж двигателя, сбитие гусениц и полевой ремонт.

---

## Основные возможности (v0.2.0-beta)

### Управление в танке
- **ПКМ (Правая кнопка мыши)** или **G** — выстрел из главного орудия
- **W / A / S / D** — движение и разворот на месте
- **R** — смена типа снаряда (**ББ** → **КС** → **ОФ**)
- **V** (и **колесо мыши** в прицеле) — снайперский режим (**Выкл** → **2x** → **4x**) с дальномером и динамическим маркером бронепробития
- **B** (удержание) — стрельба из спаренного пулемёта по пехоте/мобам
- **F** — включение **Форсажа двигателя** (+35% мощности на 8 секунд)
- **C** — смена камуфляжа танка (**Лесной** / **Пустынный** / **Зимний**)

### Типы снарядов и взаимодействие с миром
| Снаряд | Пробитие | Ср. урон | Рикошет | Разрушение блоков | Особенности |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **ББ (AP)** — Бронебойный | **165 мм** | **45 HP** | ≥ 70° | **Нет** | Высокая скорость полёта, настильная баллистика |
| **КС (HEAT)** — Кумулятивный | **235 мм** | **38 HP** | ≥ 82° | **Нет** | Пробивает тяжёлую лобовую броню, поджигает цели |
| **ОФ (HE)** — Осколочно-фугасный | **45 мм** | **60 HP** | Нет | **Да** | Наносит осколочный урон даже без пробития, сбивает гусеницы и разрушает укрепления |

### Система бронирования и модулей (WoTB)
- **Дифференцированная броня**:
  - **Лоб**: `155 мм` под конструктивным наклоном (высокая приведённая броня, возможны рикошеты ББ).
  - **Борта**: `85 мм` (при попадании есть шанс **сбить гусеницу**, обездвижив танк на 5 с).
  - **Корма**: `45 мм` (уязвима для фугасов, при пробитии возможен **пожар двигателя**).
- **Танковый HUD и Снайперский прицел**:
  - Оптический прицел с виньеткой, шкалой тысячных, дальномером (в метрах) и **цветовым индикатором бронепробития** при наведении на танк (Зелёный — пробитие, Жёлтый — ~50/50, Красный — рикошет / не пробьёт).
  - В аркадном режиме отображается маркер реального положения ствола во время плавного поворота башни (`6.5°/тик`, УВН `-10°..+22°`).
  - Панель состояния танка (полоса `200 HP`, спидометр в `км/ч`, передача `FWD/REV/N`, статус гусениц и форсажа) и слоты боекомплекта (`ББ: 24`, `КС: 12`, `ОФ: 12`).

## Предметы и крафты

1. **Спавнер боевого танка (`wotbminecraft:tank_spawner`)**:
   ```
   [#][#][#]    # — железный блок
   [#][R][#]    R — блок красного камня
   [I][I][I]    I — железный слиток
   ```
2. **Танковый боекомплект (`wotbminecraft:tank_ammo`)** — пополняет `+12 ББ, +6 КС, +6 ОФ` (ПКМ по танку снаружи или `Shift + ПКМ` внутри):
   ```
   [I][I][I]    I — железный слиток
   [G][G][G]    G — порох
   [I][I][I]
   ```
3. **Танковый ремкомплект / Ключ (`wotbminecraft:tank_repair_kit`)**:
   - **ПКМ по танку** — чинит `+60 HP` и мгновенно восстанавливает сбитые гусеницы.
   - **Shift + ПКМ по пустому танку** — аккуратно сворачивает танк обратно в предмет с сохранением его HP, боекомплекта и камуфляжа!
   - **Shift + ПКМ внутри танка** — экстренный ремонт в бою.
   ```
   [ ][I][ ]    I — железный слиток
   [ ][R][I]    R — красная пыль (редстоун)
   [I][ ][ ]
   ```

## Установка

1. Установите **Minecraft 1.12.2** и **Forge 14.23.5.2860**.
2. Скопируйте готовый файл `releases/wotbminecraft-beta-0.2.0-beta.jar` в папку `.minecraft/mods`.

## Сборка из исходников

```bash
./gradlew build
```
Готовый архив появится в `build/libs/`.
